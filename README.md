# Yuk Saling Berguru

Plugin Claude untuk peserta kelas Yuk Saling Berguru. Isinya 5 skill:

1. Resume meeting
2. Slide presentasi
3. Tulisan tanpa gaya AI
4. Pemandu Brand Hub
5. Bangun website

Penjelasan tiap skill ada di [plugins/yuk-saling-berguru/README.md](plugins/yuk-saling-berguru/README.md).

## Cara pasang di claude.ai atau aplikasi desktop

1. Buka **Customize**, lalu **Plugins**.
2. Klik **Add**, pilih **Add marketplace**.
3. Ketik `mellakamal/yuk-saling-berguru`.
4. Klik **Add** pada plugin **Yuk Saling Berguru**.

## Cara dapat update otomatis

Buka marketplace yang tadi ditambahkan, lalu nyalakan **Sync automatically**.
Kalau mau cek manual, klik **Check for updates**.

## Cara pasang di Claude Code

Ketik dua perintah ini satu per satu:

```
/plugin marketplace add mellakamal/yuk-saling-berguru
```

```
/plugin install yuk-saling-berguru@yuk-saling-berguru
```
