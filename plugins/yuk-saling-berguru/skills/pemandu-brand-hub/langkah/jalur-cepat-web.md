# Jalur cepat web

Dipakai kalau artist datang dengan permintaan web duluan, misalnya "aku mau bikin website", "bikinin Carrd", atau "aku butuh portofolio online secepatnya". Baca juga pengetahuan/web.md.

Tujuannya artist cepat punya web pertama di Carrd, tanpa melompati bahan yang membuat web itu bekerja. Web tanpa positioning, harga, dan cara order hanya jadi galeri.

## Buka dengan rencana singkat

Sambut permintaannya, lalu jelaskan dalam dua atau tiga kalimat:

> Bisa, kita bikin web pertamamu di Carrd dulu, supaya portofolio langsung bisa dibagikan. Supaya web-nya mendatangkan order, aku perlu lima bahan: siapa kamu dan untuk siapa, karya terbaik, harga, aturan order singkat, dan cara klien menghubungi. Kita kumpulkan cepat lewat ngobrol, lalu aku siapkan semua teksnya.

Kalau artist ingin langsung web sendiri tanpa Carrd, jelaskan bahwa web sendiri butuh bahan yang sama ditambah Claude Code dan hosting. Tawarkan Carrd sebagai versi pertama yang bisa tayang hari ini sambil web sendiri disiapkan. Kalau artist tetap memilih web sendiri, ikuti pengetahuan/web.md bagian Tahap 2 dengan bahan dari jalur ini.

## Urutan

1. **Pemetaan ringkas.** Dari Tahap A, ambil hanya: link yang ada, model bisnis, layanan utama, dan pasar (luar negeri, lokal, atau dua-duanya). Pasar menentukan Bahasa publik.
2. **Ruang kerja.** Tawarkan Tahap B sekarang, karena teks web dan file karya perlu tempat simpan. Kalau artist belum mau, simpan semua bahan di percakapan dan tulis ulang ke Brand Hub saat Tahap B dikerjakan.
3. **Positioning dan suara, satu putaran.** Pakai otak-marketing.md. Hasilkan kalimat positioning dan bio pendek. Tidak perlu riset kompetitor lengkap di sini.
4. **Karya.** Minta 6 sampai 9 karya terbaik lewat link atau upload. Utamakan video. Pilih bersama dengan kriteria Langkah 4 secara singkat.
5. **Harga.** Pakai penawaran.md dan file niche yang sesuai. Isi harga usulan, lalu sampaikan bahwa kalau studio punya standar harga sendiri (lokal dan global), kirim saja dan nanti direvisi.
6. **ToS singkat dan FAQ.** 5 sampai 8 poin dari penawaran.md. Minta artist mengecek, karena ini janji ke pembeli.
7. **Cara order.** Tentukan tombol: platform order yang sudah ada, Google Form sederhana (lihat Langkah 7 Pintu 1), Discord, atau WhatsApp. Paket gratis Carrd tidak punya form bawaan, jadi form dipasang sebagai tombol link.
8. **Bangun Carrd.** Ikuti pengetahuan/web.md bagian Tahap 1.
9. **Pasang link.** Setelah halaman aktif, ganti link di bio yang sudah ada ke halaman ini.

## Catat di Brand Hub

- Bahan yang dibuat di jalur ini ditandai **sementara** di Profil Brand dan Daftar Harga.
- Di Tasks, Langkah 5 diberi Status Jalan dengan catatan "Tahap 1 Carrd aktif". Langkah 5 baru Selesai setelah temuan audit beres, atau setelah artist memutuskan Carrd sudah cukup.
- Tambah baris pengingat untuk merapikan bahan sementara di Langkah 1, 4, 6, dan 7.

## Setelah web pertama tayang

Kembali ke urutan biasa dari langkah pertama yang belum Selesai. Sampaikan ke artist bahwa langkah berikutnya akan memperkuat web ini, misalnya bio yang seragam dan jalur order yang lengkap. Setelah Langkah 7 selesai, tawarkan web sendiri lewat Claude Code (pengetahuan/web.md bagian Tahap 2).
