# Niche: Maskot brand dan figur siap cetak

Dibaca kalau brand menerima pesanan maskot (2D atau 3D) untuk usaha, komunitas, sekolah, atau kreator, atau membuat model karakter yang siap dicetak 3D (file STL) dan figur fisik. Data per November 2026. Harga dan aturan platform cek ulang sebelum dipakai.

## Peta niche

Maskot bisa 2D atau 3D. Cetak 3D hanya berlaku untuk model 3D. Ada empat jenis produk yang sering tertukar, jadi tanyakan dulu yang mana yang ditawarkan studio:

| Produk | Yang dikirim ke klien | Dipakai untuk |
|---|---|---|
| Maskot 2D | PNG, file vektor (AI, SVG, EPS), lembar pose | Logo, media sosial, kemasan, kaos |
| Maskot 3D untuk tampilan | Render gambar, video putar, file 3D (FBX, GLB, BLEND) | Iklan, website, video, animasi |
| Model siap cetak | File STL atau 3MF yang sudah dicek bisa dicetak | Klien mencetak sendiri atau lewat jasa cetak |
| Figur fisik | Figur hasil cetak, polos atau dicat, dikirim ke alamat | Hadiah, koleksi, merchandise, pajangan toko |

Studio 3D bisa menjual satu karakter dalam beberapa bentuk sekaligus. Ini cara paling mudah untuk menaikkan nilai order.

## Siapa pembelinya

| Jenis | Yang dicari | Ketakutan utama |
|---|---|---|

## Produk dan cara menyusunnya

### Maskot 2D

Paket yang umum di Fiverr naik bertahap: PNG resolusi biasa untuk paket dasar, lalu file vektor, lalu tambahan seperti mockup atau beberapa pose. Hak pakai komersial sering hanya ada di paket menengah ke atas. Tambahan yang umum: pose atau ekspresi baru, versi hitam putih, panduan pemakaian maskot, logo teks.

### Maskot 3D untuk tampilan

Susun dari: jumlah sudut render, ada atau tidaknya rig (untuk animasi), jumlah pose, dan file sumber. File sumber biasanya dihargai terpisah.

### Model siap cetak (STL)

Inilah yang membedakan model cetak dari model tampilan. Model yang bagus di layar belum tentu bisa dicetak. Syarat dasarnya:

- **Watertight atau manifold**, artinya permukaan tertutup rapat tanpa lubang dan tanpa bidang yang saling tembus.
- **Ketebalan dinding cukup.** Untuk resin, panduan umum menyebut minimal sekitar 0,5 sampai 1 mm. Untuk FDM (filamen) lebih tebal, sekitar 0,8 sampai 1,2 mm atau lebih. Cek panduan jasa cetak yang dipakai.
- **Bagian dipotong (split) dengan pengunci (key)** kalau figur besar atau rumit, supaya mudah dicetak dan dirakit.
- **Dilubangi (hollow) dengan lubang buang resin** untuk figur resin besar, supaya hemat bahan.
- **Skala jelas**, misalnya tinggi figur dalam mm atau skala miniatur 28 mm atau 32 mm.
- **Alas atau base**, supaya figur bisa berdiri.
- **Dicek di slicer** (misalnya Lychee atau Chitubox untuk resin, PrusaSlicer atau Bambu Studio untuk FDM).

Format yang dikirim: STL untuk satu warna, 3MF kalau perlu warna atau bagian yang tersusun. Tulis di paket apakah file sumber (BLEND, ZTL) ikut atau tidak.

### Figur fisik

Pilihan studio:
1. **Cetak sendiri**, kalau punya printer resin atau FDM.
2. **Lewat jasa cetak lokal.** Di Indonesia jasa cetak resin di marketplace biasanya menghitung per gram (setelah support dihitung di slicer), dan banyak yang menolak komplain kalau file tidak siap cetak. Jadi file harus sudah dicek dulu.
3. **Tanpa figur fisik**, hanya menjual file.

Harga figur fisik dihitung dari: biaya modeling, bahan (termasuk support), waktu mesin, risiko gagal cetak, pengamplasan dan pengecatan, kemasan, dan ongkir. Ongkir sebaiknya dihitung terpisah setelah figur jadi.

## Aturan platform yang penting

- **Etsy dan cetak 3D.** Sejak Juni 2025, barang yang dibuat dengan mesin seperti printer 3D harus berasal dari desain penjual sendiri. Mencetak file orang lain, walau sudah membeli lisensi komersial, berisiko melanggar. Ini menguntungkan studio yang membuat model sendiri. Cek ulang aturan Creativity Standards Etsy sebelum membuka toko.
- **Lisensi file STL.** File di Cults3D, MyMiniFactory, dan Printables punya lisensi masing-masing. Banyak yang hanya untuk pemakaian pribadi. Studio yang menjual file sendiri harus menulis lisensinya: pribadi saja, boleh dicetak dan dijual terbatas, atau komersial penuh.
- **Batas ukuran file.** Etsy membatasi ukuran file digital (sekitar 20 MB per file menurut panduan 2026). Model detail sering lebih besar, jadi siapkan versi terkompresi atau jual lewat platform STL.
- **Fan art.** Figur dari karakter milik pihak lain berisiko melanggar merek dagang walau lisensi file mengizinkan. Hindari menjual figur fan art tanpa izin.
- **Tanggung jawab produk fisik.** Figur dengan bagian kecil tidak cocok untuk anak kecil. Tulis peringatan kalau figur dijual sebagai pajangan.

## Hak pakai maskot

Maskot dipakai untuk usaha, jadi hak pakainya harus sangat jelas di ToS dan paket:
- Apakah klien boleh memakai maskot di logo, kemasan, iklan, dan merchandise.
- Apakah hak cipta pindah ke klien atau studio hanya memberi lisensi.
- Apakah klien boleh mengubah maskot atau meminta studio lain membuat pose baru.
- Apakah studio boleh memajang maskot di portofolio. Klien brand kadang meminta karya dirahasiakan sampai peluncuran, jadi tawarkan sebagai pilihan.

## Yang ditakutkan pembeli dan cara menjawabnya

| Ketakutan | Cara menjawabnya |
|---|---|
| Maskot tidak cocok dengan brand | Tanya nilai brand, target pembeli, dan warna dulu. Kirim 2 sampai 3 konsep sketsa |
| Pose berikutnya tidak konsisten | Tawarkan lembar karakter (turnaround dan ekspresi) dalam paket |
| File tidak bisa dicetak | Tulis "sudah dicek di slicer", sertakan foto hasil cetak uji kalau ada |
| Figur tidak mirip foto | Minta foto depan, samping, dan belakang. Tunjukkan render sebelum dicetak |
| Figur rusak di jalan | Jelaskan cara pengemasan dan siapa menanggung kerusakan |

## Ide penawaran

- **Satu karakter, banyak bentuk:** maskot 2D, model 3D, file STL, dan figur fisik sebagai paket bertingkat.
- **Paket peluncuran brand:** maskot, 3 pose, logo dengan maskot, dan beberapa stiker untuk media sosial.
- **Figur kreator:** versi chibi siap cetak dari avatar VTuber atau maskot kreator, cocok sebagai tambahan setelah order avatar.
- **Merchandise kecil:** gantungan kunci, magnet, atau pin dari maskot yang sama.
- **Lisensi cetak untuk klien:** klien membeli hak mencetak dan menjual figur maskot mereka sendiri.

## Diagnosa khusus niche ini

- **Pembeli maskot hanya memesan paket dasar:** hak pakai komersial dan file vektor belum terlihat penting. Jelaskan di deskripsi paket apa bedanya untuk usaha mereka.
- **Banyak pertanyaan, sedikit order untuk figur fisik:** harga dan ongkir tidak jelas. Tulis contoh harga dan cara hitung ongkir.
- **Komplain cetak gagal:** file belum dicek atau dinding terlalu tipis. Tambahkan langkah pengecekan slicer ke alur kerja.
- **Order sekali lalu hilang:** tawarkan pose, merchandise, atau figur sebagai order berikutnya.
