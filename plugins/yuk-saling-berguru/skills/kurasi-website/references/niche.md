# Checklist Khusus Niche

Kenali niche dari isi web. Kalau web melayani lebih dari satu niche, pakai bagian yang sesuai untuk tiap layanan. Kalau niche tidak ada di sini, lewati file ini.

## VTuber / Live2D / model 3D
- Ada showreel atau video demo gerakan (rigging, ekspresi, physics rambut dan pakaian), bukan hanya gambar diam.
- Disebutkan apa yang termasuk: art saja, rigging saja, atau keduanya; jumlah ekspresi dan toggle; format file (cmo3, moc3, VRM, VRoid).
- Kompatibilitas software disebut (VTube Studio, VSeeFace, Warudo, dan sebagainya).
- TOS komisi jelas: hak streaming dan monetisasi, kredit wajib atau tidak, boleh dimodifikasi atau tidak.
- Antrean atau status slot komisi terlihat (open/closed, jumlah slot).
- Ada contoh debut atau klien VTuber yang sudah memakai model.

## Ilustrasi umum / karakter / komisi personal
- Kategori jelas: headshot, half body, full body, chibi, background.
- Harga tambahan jelas: karakter tambahan, background, penggunaan komersial, file PSD.
- Daftar "Will draw / Won't draw".
- Contoh tahapan (sketsa → lineart → warna) untuk menunjukkan proses.

## Maskot / ilustrasi brand
- Contoh maskot dalam penerapan nyata: kemasan, sosmed, merchandise, signage.
- Paket menyebut jumlah pose atau ekspresi, turnaround, dan panduan penggunaan maskot.
- Hak cipta dan penyerahan hak ke klien dijelaskan.
- Bahasa dan contoh ditujukan ke pemilik bisnis, bukan sesama artist.

## Buku anak / ilustrasi picture book
- Contoh spread halaman lengkap dengan teks, bukan hanya ilustrasi lepas.
- Konsistensi karakter antarhalaman terlihat.
- Disebut format kerja: ukuran buku, bleed, jumlah halaman, file siap cetak.
- Kerja sama dengan penulis atau penerbit dijelaskan (royalti atau beli putus).

## Game asset
- Contoh asset dalam konteks game: sprite sheet, UI dalam layar game, tileset terpasang.
- Format dan spesifikasi teknis: resolusi, PNG transparan, sprite sheet, file sumber.
- Gaya yang dikuasai jelas (pixel art, hand-painted, low poly).
- Lisensi untuk game komersial dijelaskan.

## TTRPG (token, peta, karakter, ilustrasi modul)
- Contoh peta dengan grid dan tanpa grid, ukuran dalam satuan grid.
- Token dalam format siap pakai di VTT (Roll20, Foundry, Owlbear Rodeo).
- Lisensi untuk publikasi modul komersial atau pemakaian pribadi.
- Kalau melayani Patreon atau pembelian aset, link toko jelas.
