# Yuk Saling Berguru

Plugin berisi tujuh skill yang dipakai di kelas Yuk Saling Berguru. Pasang sekali, lalu skill ini bisa dipakai di chat Claude, Cowork, dan Claude Code.

## Isi

| Skill | Cara memanggil | Gunanya |
|---|---|---|
| Resume meeting | "kawal meeting", lalu "susun resume" | Mencatat selama meeting, lalu menyusun resume berbentuk slide |
| Slide presentasi | Minta slide atau deck apa pun | Aturan tata letak, font, dan diksi agar slide rapi dan enak dibaca |
| Tulisan tanpa gaya AI | Otomatis saat menulis teks untuk orang lain | Menghindari tanda baca dan pola kalimat yang terasa seperti tulisan mesin |
| Pemandu Brand Hub | "mulai panduan Brand Hub", "lanjut panduan" | Memandu artist atau studio membangun akun branding dari nol |
| Bangun website | "bikin website", "lanjut web" di chat | Untuk artist dan studio kreatif: menyusun blueprint di chat, lalu memberi prompt bertahap untuk Claude Code |
| Bangun website di Code | "bikin website", "lanjut web" di dalam Claude Code | Memandu dan membangun website langsung di folder proyek, dari pemetaan sampai tayang dan SEO |
| Kurasi website | "kurasi website" plus link, screenshot, atau folder proyek. "kurasi lengkap" untuk ikut membandingkan pesaing, "kurasi ulang" setelah diperbaiki | Menilai web yang sudah jadi di 11 area, mensimulasikan calon pembeli, lalu memberi prompt perbaikan siap tempel untuk Claude Code |

## Sebelum mulai
- Saat pertama memakai resume meeting atau slide, Claude akan menanyakan nama, palet warna, dan font. Kalau belum punya font brand, Claude menawarkan tiga pasangan font. Simpan jawabannya sebagai preferensi agar tidak ditanya lagi.
- Pemandu Brand Hub memakai Google Drive atau Notion. Sambungkan connector-nya dari menu Plugins atau Customize.
- Bangun website membutuhkan Claude Code (aplikasi desktop atau claude.ai/code), akun GitHub, dan akun hosting.
- Kurasi website paling lengkap kalau browser tersedia (built-in browser atau Claude in Chrome) untuk membuka link live.

## Hasil yang tidak seragam
Setiap brand perlu suara dan tampilan sendiri, jadi hasilnya dibuat dari karakter tiap pemakai:
- Contoh di dalam skill hanya menunjukkan pola. Hook, caption, bio, pengumuman, dan teks web selalu ditulis baru dengan suara brand masing-masing.
- Claude akan menanyakan apa yang membuat studiomu berbeda dari studio lain di niche yang sama. Jawabannya dipakai untuk desain, teks, dan konten.
- Desain kasar web dimulai dari dua sampai tiga arah yang berbeda, lalu kamu memilih satu.
- Fitur unggulan web dan font slide dipilih dari karakter studiomu, bukan dari satu bawaan yang sama untuk semua orang.
- Nama channel Discord, judul form order, nama paket di web, dan jadwal posting juga disusun dari brandmu. Panduannya hanya menyebut fungsinya.
